# 壹、研究動機與問題定義

## 1.1 研究背景

台積電（2330.TW）是全球晶圓代工龍頭，市值逾 20 兆台幣，其股價牽動台灣整體股市（台積電約佔台股市值 30%）。台積電股價受到多層次因素影響：

- **基本面**：法說會、季報、EPS 超/低預期
- **總體經濟**：美國升降息、半導體景氣循環、貿易政策
- **市場情緒**：外資動向、散戶 PTT 討論熱度、財經新聞輿論

傳統量化模型僅使用技術指標（RSI、MACD）或總經因子（VIX、SOX），忽略了「語言情緒」這個重要的市場信號。本研究嘗試結合 **自然語言處理（NLP）** 與 **機器學習（ML）**，構建一套橫跨 26 年的多源融合預測系統，並以嚴謹的消融實驗量化每類特徵的實際貢獻。

## 1.2 研究問題

> **「結合 NLP 情緒分析（新聞 + PTT）與技術/總經指標，是否能在不同市場情境（金融危機、疫情、升息循環）下，顯著提升台積電次日漲跌方向的預測準確度？」**

## 1.3 研究貢獻

1. **資料廣度**：全球首個涵蓋台積電 26 年（2000–2026）的多源融合預測矩陣
2. **跨情境驗證**：7 個歷史關鍵年份的滾動式壓力測試（Stress Testing）
3. **情緒量化**：以 Text2Vec 將中文財經文本轉化為連續情緒分數
4. **可重現性**：全流程開源，提供 Look-Ahead Bias 驗證報告

# 參、自然語言處理（NLP）情緒分析

## 3.1 系統架構：Text2Vec + Cosine Similarity

本系統採用 **語義向量相似度（Semantic Vector Similarity）** 方法，不使用傳統字典式方法（如 LIWC、SentiWordNet）。

### 模型選擇

```
模型：shibing624/text2vec-base-chinese
架構：BERT-based SentenceTransformer (12 層 Transformer)
預訓練：大規模繁/簡體中文語料
向量維度：768 維（壓縮後）
用途：將中文句子映射到語義向量空間
```

相較於傳統方法的優勢：
- **語義理解**：「台積電訂單滿載」和「台積電產能全滿」被識別為相同含義
- **零樣本分類**：不需要人工標注訓練資料
- **跨文體適應**：同時處理新聞標題（正式）和 PTT 推文（口語）

## 3.2 Bullish / Bearish 錨定向量

系統預先定義 5 個多頭（Bullish）和 5 個空頭（Bearish）錨定句子：

**多頭錨定句（各 1 個範例）：**
> 「台積電股價大漲，市場情緒極度樂觀，投資人大量買進，做多看漲」  
> 「台積電業績超預期，法人瘋狂加碼，股價創新高，多頭氣勢如虹」

**空頭錨定句（各 1 個範例）：**
> 「台積電股價暴跌，市場恐慌性拋售，投資人爭相出逃，做空看跌」  
> 「台積電面臨嚴重利空，崩盤風險極高，恐慌賣壓湧現，空方獲勝」

每類 5 個句子的向量**取平均後正規化**，形成穩健的方向性錨點。

## 3.3 情緒分數計算公式

對每日所有新聞標題 $\{t_1, t_2, ..., t_n\}$：

$$\text{score}_i = \frac{\cos(v_i,\ \vec{bull})}{\cos(v_i,\ \vec{bull}) + \cos(v_i,\ \vec{bear})}$$

$$\text{PTT\_Raw\_Score}_{\text{day}} = \frac{1}{n} \sum_{i=1}^{n} \text{score}_i$$

其中 $v_i$ 是第 $i$ 個標題的語義向量，$\vec{bull}$ 和 $\vec{bear}$ 是多頭/空頭錨定向量。

**分數解讀：**
- `score → 1.0`：強烈多頭情緒
- `score = 0.5`：中立（無情緒偏向）
- `score → 0.0`：強烈空頭情緒

**無資料填補規則：** 無新聞/討論的日期，填入中立值 `0.5`，**嚴禁**前後日插補（避免未來資訊污染）。

## 3.4 情緒分數分布

| 特徵 | 均值 | 標準差 | 備註 |
|------|------|--------|------|
| `News_Raw_Score` | 0.5250 | 0.0702 | 有效覆蓋後提升 16 倍 |
| `PTT_Raw_Score` | 0.5013 | 0.0085 | 受限於 PTT 覆蓋率 |

> ⚠️ **學術誠信說明：** 情緒分數標準差相對較小（0.07 / 0.008），這表示 NLP 特徵的區辨能力受限於：(1) 許多日期無資料（填中立值 0.5）；(2) 財經新聞語言中立偏向。這是本研究的主要侷限之一。

# 肆、技術指標工程

## 4.1 特徵設計原則

**嚴格遵守無前瞻性偏誤（No Look-Ahead Bias）原則：**

所有特徵在 $t$ 日的計算，僅使用 $t$ 日及 $t$ 日以前的資料。經逐行程式碼審查及數值驗證（誤差 $< 5.4 \times 10^{-16}$），確認無未來函數。

## 4.2 技術指標明細

### RSI（相對強弱指標）

$$RSI_{14} = 100 - \frac{100}{1 + RS}, \quad RS = \frac{\overline{Gain}_{14}}{\overline{Loss}_{14}}$$

使用 **Wilder EMA**（`com = period - 1 = 13`），與 TradingView 標準一致。  
**含義：** 衡量近期漲跌幅的相對強弱，RSI < 30 超賣，RSI > 70 超買。

### MACD（移動平均收斂發散）

$$MACD = EMA_{12}(Close) - EMA_{26}(Close)$$
$$Signal = EMA_9(MACD)$$

**含義：** 捕捉中短期價格動能的方向與強度。

### 多時間框架歷史報酬率

$$Ret_{wD}(t) = \frac{Close_t - Close_{t-w}}{Close_{t-w}}, \quad w \in \{5, 10, 20, 42\}$$

對應約 **1 週、2 週、1 個月、2 個月** 的動能因子。

### 年化滾動波動率

$$Vol_{42D}(t) = \sigma_{42}\left(\frac{Close_t - Close_{t-1}}{Close_{t-1}}\right) \times \sqrt{252}$$

**含義：** 近 2 個月的年化波動率，用於衡量市場不確定性。

### 42 日相對位階

$$Position_{42D}(t) = \frac{Close_t - \min_{42D}}{max_{42D} - \min_{42D}} \in [0, 1]$$

**含義：** 股價在近 2 個月高低區間的相對位置（0 = 最低，1 = 最高）。

## 4.3 預測標籤定義

$$Target\_Binary_t = \mathbb{1}\left[\frac{Close_{t+1} - Close_t}{Close_t} > 0\right]$$

使用 `shift(-1)` 實現，已驗證 **100% 完全對應次日報酬方向**（非同日）。

# 伍、機器學習模型

## 5.1 模型架構：VotingClassifier

本研究採用 **RF + XGBoost 軟投票整合模型（Soft Voting Ensemble）**：

```
VotingClassifier(
    estimators = [
        ('rf',  RandomForestClassifier),
        ('xgb', XGBClassifier),
    ],
    voting = 'soft',    # 機率平均，非多數決
    weights = [1, 1],   # 等權重
)
```

### 為何使用 Soft Voting？

- **硬投票（Hard Voting）**：RF 說「漲」，XGB 說「跌」→ 平手無法決定
- **軟投票（Soft Voting）**：RF 說「75% 漲」，XGB 說「60% 漲」→ 平均後 67.5% 漲，方向明確

軟投票能利用每個分類器的**信心程度（機率校準）**，在市場信號不確定時更穩健。

## 5.2 Random Forest 超參數

```python
RF_PARAMS = {
    'n_estimators': 300,    # 300 棵決策樹
    'max_depth': 6,          # 每棵樹最深 6 層（防止過擬合）
    'min_samples_leaf': 20,  # 葉節點至少 20 個樣本（正則化）
    'random_state': 42,
    'n_jobs': -1,            # 並行計算
}
```

### 為何選 RF？

- **非線性捕捉**：技術指標間存在非線性交互作用（如 RSI 低 + VIX 高 + SOX 跌 → 強烈空頭信號）
- **特徵重要性**：天然提供特徵貢獻度排序，增加可解釋性
- **對異常值穩健**：分裂點決策不受極端值影響

## 5.3 XGBoost 超參數

```python
XGB_PARAMS = {
    'n_estimators': 300,      # 300 輪 Boosting
    'max_depth': 4,            # 比 RF 淺（防止 Boosting 過擬合）
    'learning_rate': 0.05,    # 小步長，更穩健的梯度下降
    'subsample': 0.8,          # 每輪隨機抽 80% 樣本
    'colsample_bytree': 0.8,  # 每棵樹隨機抽 80% 特徵
    'random_state': 42,
}
```

### 為何同時使用 XGBoost？

RF 是 **Bagging**（平行訓練多棵樹，減少方差），XGBoost 是 **Boosting**（序列訓練，聚焦錯誤樣本，減少偏差）。兩者學習機制互補：

| 特性 | Random Forest | XGBoost |
|------|-------------|---------|
| 訓練策略 | Bagging（並行） | Boosting（序列） |
| 優點 | 低方差，對雜訊穩健 | 低偏差，捕捉細微模式 |
| 弱點 | 偏差較高 | 容易過擬合 |
| 互補效果 | ✓ | ✓ |

## 5.4 StandardScaler 正規化

```python
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)  # ← 只 fit 訓練集
X_test_scaled  = scaler.transform(X_test)        # ← 不 refit
```

**關鍵：** Scaler 只在訓練集 `fit`，測試集直接 `transform`。若在全資料集 fit，會引入測試集的均值/標準差資訊，構成資料洩漏（Data Leakage）。

# 陸、消融實驗設計（Ablation Study）

## 6.1 研究方法論

消融實驗（Ablation Study）源自神經科學，原指切除腦區觀察功能喪失，此處用於**逐一移除特徵子集**，量化每類特徵的獨立貢獻。

## 6.2 五種特徵組合

| 版本 | 特徵集合 | 設計目的 |
|------|---------|---------|
| ① 純NLP情緒版 | News_Raw_Score, News_Volume, PTT_Raw_Score, PTT_Volume | 純情緒能否預測？ |
| ② 純技術大盤版 | RSI, MACD, MACD_Signal, Ret_5/10/20/42D, Vol_42D, Position_42D, Volume, VIX, SOX_Ret, ADR_Ret, FX_Ret | 技術+總經的基礎線 |
| ③ 大盤+新聞版 | ② + 新聞情緒 | 新聞的邊際貢獻 |
| ④ 大盤+PTT版 | ② + PTT情緒 | PTT 的邊際貢獻 |
| ⑤ 終極完全體 | ② + ③ + ④（全部） | 完整融合是否最優？ |

## 6.3 滾動時間序列切分

```
測試年份 Y:
  ├── 訓練集: [Y-5, Y-1] 完整曆年（嚴格在測試年之前）
  └── 測試集: Y 全年（從未出現在訓練集）

範例（測試 2022 年）:
  訓練集: 2017-01-01 ~ 2021-12-31  (約 1,300 天)
  測試集: 2022-01-01 ~ 2022-12-31  (260 天)
```

**為何不用 K-Fold 交叉驗證？**  
標準 K-Fold 會用「未來資料訓練，過去資料測試」，在時間序列中這是嚴重的未來資訊洩漏。滾動窗格（Walk-Forward）是量化金融中的標準做法。

# 柒、實驗結果與分析

## 7.1 主要實驗結果

| 年份 | 情境 | 永遠猜漲 | ① NLP | ② 純技術 | ③ +新聞 | ④ +PTT | ⑤ 完全體 | Alpha |
|------|------|---------|-------|---------|--------|-------|---------|-------|
| 2008 | 金融海嘯 | 42.2% | 57.8% | **64.3%** | 63.8% | 63.8% | 63.8% | **+21.6%** |
| 2011 | 歐債/庫存 | 48.6% | 51.4% | 60.5% | 60.1% | 60.1% | **61.3%** | **+12.8%** |
| 2015 | 半導體寒冬 | 43.5% | 56.5% | 68.8% | **70.8%** | **70.8%** | 66.2% | **+22.8%** |
| 2018 | 中美貿易戰 | 50.2% | 49.8% | 64.1% | **65.0%** | **65.0%** | **65.0%** | **+14.8%** |
| 2020 | COVID-19 | 53.9% | 46.1% | **67.9%** | 67.1% | 67.1% | 65.8% | **+11.9%** |
| 2022 | 激進升息 | 44.7% | 55.3% | **72.2%** | 70.5% | 70.5% | **71.7%** | **+27.0%** |

## 7.2 結果解讀

### 發現一：技術+總經特徵（②）是最穩定的核心
